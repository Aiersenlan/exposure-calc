# 曝險計算機

正二 + 大盤 + 現金 + 信貸 + 質押的市場曝險與財務槓桿計算機，單一 HTML 檔、無任何外部依賴，離線可用。

**線上版本**：https://aiersenlan.github.io/exposure-calc/

## 這是什麼

把槓桿投資組合的風險拆成三個正交指標：

| 符號 | 名稱 | 定義 | 意義 |
|---|---|---|---|
| `m` | 市場曝險 Market Exposure | `(2×正二 + 大盤) / 總資產` | 資產側：每 100 元資產有多少在承受市場波動 |
| `g` | 財務槓桿 Financial Leverage | `總資產 / 淨值` | 負債側：借款把部位放大幾倍 |
| `E` | 股票組合曝險 Stock Portfolio Exposure | `m × g` | 淨值真正承受的曝險：大盤漲跌 1%，淨值變動 E% |

填入目前市值與負債餘額後，會自動算出：

- 曝險分解、資產負債表、目前與目標配置佔比
- 是否觸發再平衡，以及對齊目標配置所需的交易與估計成本
- 大盤 ±10%～±40% 的情境模擬（含破產判斷）
- 漂移敏感度 `D`：下跌時曝險是自動下降（安全）還是自動放大（危險）
- 下次再平衡的觸發點反推

頁面最下方附完整名詞解釋（中文／English／符號對照），適合不熟悉槓桿曝險概念的使用者。

## 使用方式

直接打開 `index.html`，或造訪上方線上版本。所有輸入欄位支援算式（例如打 `100+200` 按 Enter 會自動算成 `300`）。資料用瀏覽器 `localStorage` 自動記錄，換瀏覽器或換裝置不會同步。

## 刻意沒算的事

利率與利息、質押維持率與斷頭、信貸 DBR 22 倍規範與到期轉貸、正二每日重設造成的波動耗損——這些跟曝險比例正交但真實存在的風險，頁面底部名詞解釋有說明，但不進任何公式。
